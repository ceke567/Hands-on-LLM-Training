## 仓库怎么放内容

- `src/llm_training/`：可复用的模型、数据处理、训练和生成代码。代码随项目演进，Git 提交记录保留每次改动。
- `experiments/weekXX/`：该周的配置、关键指标、少量生成样例、问题与结论。每周完成时留下可以复查的证据。
- `data/README.md`：数据来源、许可、下载方式和划分规则。原始及处理后的大数据不提交。
- `docs/environment.md`：加速卡与软件环境。遇到兼容问题时先核对这里。
- `tests/`：以后放对训练正确性有实际帮助的检查。

## 记录约定

1. 一次实验只改动明确的配置项，并写下基线和目标。
2. 记录实际参数量、数据版本、训练步数、训练/验证 loss、峰值显存、吞吐和耗时。无法取得的指标标注原因。
3. 每次实验保存对应的配置和结果摘要；大体积 checkpoint、数据集与完整运行日志留在外部存储，并记录位置。
4. 发现异常时保留完整报错与首次异常的步数，再修改配置。
5. 不把密钥、账号信息或私人数据提交到 Git。

## 环境

当前使用 BW 异构加速卡和 DTK 适配版 PyTorch。已观察到 PyTorch 2.9.0 可以识别 1 张名为 `BW` 的设备。其他环境细节见 [环境记录](docs/environment.md)。
