## 问题与复盘结论

- **BF16 与梯度累积分别改变了什么，带来了什么代价**：
  1. *BF16 混合精度*：将运算精度降至 16 位，立省 22.2% 显存，吞吐速率直接提升 30.5%，且 Loss 下降轨迹与 FP32 高度重合（无精度代价）。
  2. *梯度累积*：通过将单次显存批大小折半（16->8）并累积 2 次后更新，使显存峰值从 4.6GB 骤降至 3.2GB（相比 FP32 基线暴降 44.8%！）。代价是多次前向/反向调度导致吞吐轻微下降（3.8万降至3.2万 tokens/s），但成功以更低显存承载等效大 Batch 训练。
- **哪个配置显存最省、哪个吞吐最高**：显存最省是 W02-03 梯度累积（3268.2 MB）；吞吐最高是 W02-02 纯 BF16（38,237 tokens/s）。
