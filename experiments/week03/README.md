### 2. 显存结构分解与证据链分析

- **静态显存 (与 Batch Size 无关)**：模型权重 + 优化器状态（AdamW 维持两份 fp32 动量）+ 梯度。100M 模型在此项固定占用约 1.2GB~1.6GB。
- **动态显存 (随 Batch Size 严格线性增长)**：前向计算各层输出的中间激活值（Activation Tensors）。每增加 32 Batch Size，激活值显存约增加 4.4GB。
- **临时计算缓冲**：如自注意力机制的大矩阵相乘，在前向计算第 512 批次时，激活值已撑满 62.81GB，导致新的注意力中间缓冲（384MB）无法分配，在前向阶段立即触发 OOM。

### 3. 修复方案验证：梯度累积等效大 Batch

若业务需要 512 的全局大 Batch Size：
- 采用显存安全的单步物理 Batch Size = 64；
- 设置梯度累积步数为 8；
- 显存峰值直接从撑爆 64GB 骤降至 9470.1 MB（压减 85%），并在单卡上成功达成等效 512 Batch Size 的无损训练。
