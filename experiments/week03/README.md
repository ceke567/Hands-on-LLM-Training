# 第 3 周实验记录｜训练故障与稳定性实验

状态：进行中。以 Obsidian 第 3 周指南为准，本页记录真实执行结果与故障排查手册。

## 目标

- 以第 2 周 100M 稳定模型为基线，主动制造并定位四大故障：OOM、Loss Spike / NaN、脏 Batch、速度异常。
- 掌握证据链排查法（症状 -> 证据 -> 原因 -> 修复 -> 验证），形成训练故障排查手册。
